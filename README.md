Удобная **Быстрая команда (Shortcut)** для macOS, которая синхронизирует запуск и закрытие Telegram с локальным прокси-клиентом. 

Она автоматически открывает **Telegram** одновременно с **TG WS Proxy**, фоном следит за процессом мессенджера и мгновенно завершает работу прокси, как только вы закрываете Telegram. 

---

### 🔋 Зачем это нужно?
* 📉 **Экономия заряда батареи:** Прокси-клиент не висит в фоне и не жрет ресурсы, когда Telegram закрыт.
* ⚡ **Автоматизация «в один клик»:** Заменяет привычную иконку Telegram в Dock на умный лаунчер.

> 🔗 Проект создан специально для использования в связке с официальным прокси: **[Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)**.

### ⚙️ Инструкция по установке и настройке

#### 1. Установка Быстрой команды
Добавьте автоматизацию в свое приложение «Быстрые команды» по прямой ссылке:
➡️ **[Скачать команду из iCloud](https://www.icloud.com/shortcuts/0de3b69be6d04db4ac4e1268cd5de142)**

#### 2. Код фонового скрипта и кастомизация
Внутри автоматизации используется легковесный фоновый Bash-скрипт (блок *«Запустить shell-скрипт»*), который проверяет состояние процесса каждые 3 секунды:

```bash
# Имена процессов (чувствительны к регистру)
APP_MAIN="Telegram"
APP_DEPENDENT="TG WS Proxy"

# Запускаем фоновый цикл отслеживания
(
while pgrep -x "$APP_MAIN" > /dev/null; do
    sleep 3
done
osascript -e "tell application \"$APP_DEPENDENT\" to quit"
) & > /dev/null 2>&1
```

📌 **Обратите внимание:** 
Если у вас установлена неофициальная сборка мессенджера (например, *Telegram Lite*) или прокси-клиент в системе называется иначе, вам **обязательно нужно зайти в настройки Быстрой команды и вручную поменять значения переменных** `APP_MAIN` и `APP_DEPENDENT` на точные имена ваших приложений. Они должны строго совпадать с названиями процессов в системе.

> **Примечание по настройке:** Убедитесь, что для этого блока в Shortcuts выбран тип оболочки `/bin/bash` или `/bin/zsh`, а параметр **«Ввод»** (Input) переключен в режим *«Не требуется»*.

#### 3. Как сделать использование удобным
Чтобы не открывать Shortcuts каждый раз:
1. Нажмите правой кнопкой мыши по карточке команды в приложении Быстрые команды.
2. Выберите **«Добавить в Dock»** (Add to Dock).
3. Перетащите её на привычное место Telegram. При желании в настройках команды можно сменить стандартную иконку на логотип телеги.
